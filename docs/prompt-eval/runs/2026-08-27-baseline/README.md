## Выводы, которые меняют план

1. **Номера строк не выдумывались.** В прогоне «только скриншот» все 6 номеров верны —
   модель читала их с полосы номеров IDE. Ошибки появились там, где пришёл текст без
   нумерации (4 из 8 неверны: `requests++` отнесено к строке 22 вместо 47, `go func` — к
   32 вместо 39–41). Отсюда R14: номер строки только когда он виден (полоса номеров или
   `N|` в `<code_text>`), цитата — всегда.
2. **Невзвешенный recall прятал главное:** прогон «только скриншот» пропустил обе
   гонки уровня Critical (G1, G2), а по recall13 выглядел просто «хуже вдвое».
3. **Текст как вход** — самый сильный рычаг на той же модели (0.23 → 0.64 взвешенного
   recall) — R15.
4. Сравнение с Sonnet 5 смешивает модель, промпт, вход и режим чата — разделяет только
   факторная сетка (README, «Порядок экспериментов», п. 1).
