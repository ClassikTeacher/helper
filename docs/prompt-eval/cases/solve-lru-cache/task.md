146. LRU Cache

Спроектируйте структуру данных — кэш с вытеснением
по принципу LRU (least recently used).

Реализуйте класс LRUCache:

  LRUCache(capacity: number)
    Инициализирует кэш положительной ёмкостью capacity.

  get(key: number): number
    Возвращает значение по ключу, если ключ есть,
    иначе возвращает -1.

  put(key: number, value: number): void
    Обновляет значение, если ключ существует.
    Иначе добавляет пару ключ-значение.
    Если количество ключей превышает capacity,
    вытесняет ключ, который использовался давнее всех.

Функции get и put должны работать
в среднем за O(1).

Пример:
  const lru = new LRUCache(2);
  lru.put(1, 1);
  lru.put(2, 2);
  lru.get(1);    // 1
  lru.put(3, 3); // вытесняет ключ 2
  lru.get(2);    // -1
  lru.put(4, 4); // вытесняет ключ 1
  lru.get(1);    // -1
  lru.get(3);    // 3
  lru.get(4);    // 4

Ограничения:
  1 <= capacity <= 3000
  0 <= key <= 10^4
  0 <= value <= 10^5
  Не более 2 * 10^5 вызовов get и put.
  Решение — без сторонних библиотек.
  Обращение через get тоже считается использованием ключа.
